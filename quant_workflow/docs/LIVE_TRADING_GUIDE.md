## 推荐方案：QMT/MiniQMT

### 为什么推荐QMT？
1. **券商官方支持**：华泰、中信、国信等主流券商都支持
2. **稳定性最高**：直接对接券商柜台，不用模拟鼠标键盘
3. **延迟低**：毫秒级下单
4. **免费**：开通权限即可使用

### 开通流程
1. 选择支持QMT的券商（华泰、中信、国信等）
2. 开通量化交易权限（通常需要50万资金门槛）
3. 下载QMT客户端
4. 获取API文档和示例代码

## 备选方案：vn.py

### 为什么选vn.py？
1. **开源免费**：完全开源，可定制
2. **多券商支持**：支持CTP、XTP等接口
3. **社区活跃**：中文社区，文档丰富
4. **功能完整**：支持回测、实盘、风控

### 安装和配置
```bash
# 安装vn.py
pip install vnpy

# 安装券商接口
pip install vnpy-ctp      # 期货
pip install vnpy-xtp       # 股票(华泰)
```

## 实盘交易脚本设计

### 核心模块
1. **信号生成器**：读取Qlib预测，生成交易信号
2. **订单管理器**：下单、撤单、订单状态跟踪
3. **风控模块**：仓位限制、止损、流动性检查
4. **执行引擎**：TWAP/VWAP执行算法
5. **监控报警**：异常检测、实时通知

### 交易流程
```
每日收盘后:
1. 更新数据 → 重新计算Alpha158特征
2. 运行模型 → 生成次日信号
3. 信号过滤 → 流动性、涨跌停、ST过滤
4. 生成订单 → 计算目标持仓 vs 当前持仓
5. 风控检查 → 单票上限、行业集中度、总仓位
6. 次日开盘 → 按计划下单执行
```

### 关键注意事项
1. **交易时间**：A股9:30-11:30, 13:00-15:00
2. **涨跌停**：主板±10%, 创业板/科创板±20%
3. **T+1制度**：当日买入次日才能卖出
4. **最小单位**：100股(1手)
5. **交易成本**：
   - 佣金：万2.5(单边)
   - 印花税：千1(卖出)
   - 过户费：十万分之一

## 风险控制清单

### 必须实现的风控
- [ ] 单票仓位上限：5%
- [ ] 单行业仓位上限：30%
- [ ] 总仓位上限：80%
- [ ] 单日最大亏损：-3%
- [ ] 累计最大回撤：-10%
- [ ] 涨跌停不交易
- [ ] ST股票不交易
- [ ] 停牌股票不交易

### 流动性过滤
- [ ] 日均成交额 > 5000万
- [ ] 过去20日日均换手率 > 1%
- [ ] 非新股(上市超过60天)
