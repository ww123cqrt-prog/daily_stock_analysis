# Qlib 策略优化计划

> **历史文档**：本文记录的是 2026-07-03 旧基线，不再代表当前严格鲁棒策略协议。当前计划见 [ROBUST_STRATEGY_PLAN.md](ROBUST_STRATEGY_PLAN.md)。

## 当前基线 (2026-07-03)

| 指标 | 含成本 | 不含成本 |
|------|--------|----------|
| 年化超额收益 | 3.40% | 8.24% |
| 信息比率 | 0.26 | 0.63 |
| 最大回撤 | -13.27% | -13.04% |
| 交易成本占比 | **58%** | - |

**核心问题**：换手率过高导致交易成本吞噬大部分收益。

## 优化方向（按优先级排序）

### Phase 1: 降换手 — 交易成本优化（预期收益提升最大）

**目标**：将交易成本占比从58%降到20%以下

| 方案 | 说明 | 预期效果 |
|------|------|----------|
| 调仓频率降低 | 从每日调仓改为每周/双周 | 换手率降5-10x |
| 换手率上限 | 每日最多换仓20% | 限制极端调仓 |
| 渐进式调仓 | 只在排名大幅变动时才换仓 | 减少噪声交易 |
| 持仓数量优化 | topk=50 → topk=30或topk=100 | 测试不同集中度 |

### Phase 2: 市场择时 — 趋势过滤 + 仓位管理

**目标**：在熊市/震荡市降低仓位，减少回撤

| 方案 | 说明 |
|------|------|
| MA趋势过滤 | 沪深300在200日均线下方时降仓50% |
| 波动率仓位 | 市场波动率高时降低总仓位 |
| 动态topk | 牛市topk=50，熊市topk=20 |

### Phase 3: 风险控制 — 回撤保护

**目标**：最大回撤控制在-10%以内

| 方案 | 说明 |
|------|------|
| 最大回撤止损 | 累计回撤超-8%时清仓，等待恢复 |
| 行业分散 | 单行业不超过30%仓位 |
| 个股集中度 | 单只股票不超过5%仓位 |

### Phase 4: 模型增强（中长期）

| 方案 | 说明 |
|------|------|
| 特征工程 | 添加估值因子(PE/PB)、资金流因子 |
| 集成学习 | LGB + CatBoost + 线性模型集成 |
| 超参数贝叶斯优化 | Optuna搜索最优超参数 |
| Walk-forward验证 | 滚动训练窗口避免过拟合 |
